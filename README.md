# Fight Club PS Store — كتالوج ألعاب الحسابات

نسخة أولى مبنية على بوستر الألعاب الـ67 الذي قدمه أحمد ربيع. مخصصة للحسابات فقط، دون ألعاب الأجهزة المعدلة أو فواتير أو دفع إلكتروني.

## الملفات

مجلد `dist` يحتوي الموقع الجاهز بالكامل. لا يحتاج تثبيت مكتبات أو بناء أو خادم بيانات. يعمل على GitHub Pages ويمكن فتح `index.html` محليًا لمعاينة الواجهة.

- `index.html`: الواجهة العربية، طرق التحميل، والنصائح.
- `styles.css`: التصميم المتجاوب.
- `app.js`: الاختيار والبحث والمراجعة ورسالة واتساب.
- `catalog.js`: مصدر البيانات الذي تستخدمه الواجهة.
- `catalog.json`: نسخة من نفس البيانات للقراءة والتحرير.
- `assets`: الأغلفة وشعار المكتب، بترميز WebP غير فاقد. تمت مقارنة البكسلات مع المصادر بعد التحويل.

## السلوك

- اختيار جهاز PS4 يظهر 64 عنصرًا؛ اختيار PS5 يظهر الـ67، مع زر لعرض إصدارات PS5 الأربعة فقط.
- ألعاب PS4 المعروضة على PS5 تحمل تعريف نسخة PS4؛ لا يعد ذلك ترقية إلى نسخة PS5.
- يمكن البحث بالاسم العربي أو الإنجليزي وتصفية الألعاب حسب النوع.
- الجهاز والاختيارات وطريقة التحميل تُحفظ في المتصفح محليًا. الاسم والملاحظات لا يُحفظان تلقائيًا.
- لا يوجد تسجيل دخول أو تجميع بيانات أو تحليلات أو قاعدة بيانات أو خدمات طرف ثالث لتحميل الخطوط.
- العميل يراجع قائمة اختياراته ويختار نظام التحميل، أو «ساعدني أختار».
- زر واتساب يفتح رسالة جاهزة على الرقم المصري 01015505669، بالصيغة الدولية 201015505669؛ العميل يضغط إرسال داخل واتساب بنفسه.
- يوجد بديل لنسخ رسالة الطلب. نجاح الإرسال النهائي يحدث داخل واتساب، وليس داخل الموقع.
- لا تعرض الواجهة أسعارًا أو مساحات غير مؤكدة؛ الطلب استفسار يتأكد سعره وتوفره مع المكتب.

## مراجعة البيانات قبل نشر رابط العملاء

1. أكد أحمد توفر Uncharted للفور والفايف. العنصر رقم 44 يظهر باسم **Uncharted 4 + The Lost Legacy** عند اختيار PS4، وباسم **Uncharted: Legacy of Thieves Collection** عند اختيار PS5، وتُرسل النسخة المناسبة في رسالة واتساب. بقي نفس الكود والرقم للحفاظ على الاختيارات السابقة. بذلك يوجد 64 عنصرًا متاحًا للفور، و67 للفايف تشمل 4 إصدارات PS5. الغلاف الأصلي المقدم محفوظ دون تعديل.
2. Assassin’s Creed Mirage صُنفت ضمن إصدار PS5 المتاح في البوستر. لا يعني ذلك أن اللعبة ليس لها إصدار PS4؛ لم يُفترض توفر حساب PS4 غير مذكور.
3. Until Dawn: Rush of Blood وVR Ping Pong Pro يحتاجان PS VR وملحقاته المناسبة، مع تأكيد تجهيزات PS5 مع المكتب.
4. الأغلفة مقتطعة من الصور الأصلية المقدمة؛ لم يُعد رسمها أو تغيير ألوانها أو تحسين مضمونها. دقة الأغلفة القديمة محدودة بدقة المصدر. استخدام صور أصلية منفردة أعلى دقة سيحسن التكبير دون أي إعادة رسم.
5. شرح الأوفلاين مبني على شروط خدمة المكتب كما قدمها أحمد. ليس قاعدة عامة من Sony تقول إن مجرد الاتصال بالإنترنت يغلق كل الحسابات.
6. أي تفاصيل عن تسليم الحسابات باسم العميل أو الإضافة والتحديث تُؤكد طبقًا لاتفاق الخدمة الفعلي.

## تحديث الألعاب

احتفظ بنفس `id` للألعاب القائمة حتى تستمر الاختيارات المحفوظة صحيحة. لكل لعبة اسم وإصدار وأجهزة متوافقة ومسار صورة ووسوم بحث وتصنيفات. يمكن تعديل `catalog.json` ثم تشغيل:

```text
python3 sync_catalog.py
```

يُحدث الأمر `catalog.js` بعد التحقق من عدم تكرار الأكواد ووجود الصور. عند الاستضافة على GitHub ارفع الملفين المعدلين والصور الجديدة. يمكن أيضًا تعديل `catalog.js` مباشرة، على أن تتم مزامنة نسخة JSON معه لاحقًا.

## النشر على GitHub Pages

ملف ZIP المرفق يضع محتويات `dist` في الجذر، فلا تحتاج اختيار مجلد dist في GitHub.

1. افتح مستودعًا مخصصًا للكتالوج في حساب GitHub.
2. ارفع محتويات ZIP بعد فك الضغط، مع وجود `index.html` ومجلد `assets` في جذر المستودع. رفع ZIP نفسه لا ينشر الموقع.
3. من Settings ثم Pages، اختَر Deploy from a branch.
4. اختَر فرع main والمجلد /(root)، ثم Save.
5. انتظر نجاح النشر، وافتح الرابط الذي تعرضه GitHub، وجرب اختيار الألعاب ومراجعة رسالة واتساب من موبايل.

المسارات كلها نسبية وتعمل عند الاستضافة داخل مسار مستودع GitHub Pages. لا يوجد دومين أو حساب GitHub مضمَّن في الكود.

## التحقق
